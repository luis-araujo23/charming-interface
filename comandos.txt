EN telefono contra Vercel (produccion)

flutter run --dart-define=API_BASE_URL=https://TU-PROYECTO.vercel.app
flutter build apk --dart-define=API_BASE_URL=https://TU-PROYECTO.vercel.app

================================================================================
CHECKLIST DEPLOY VERCEL (web)
================================================================================
1. En Vercel: Import repo → Root Directory = web
2. Variables de entorno (Production + Preview):
   - AUTH_SESSION_SECRET   (min 32 chars aleatorios)
   - APP_URL               = https://tu-proyecto.vercel.app
   - SUPABASE_URL
   - SUPABASE_SERVICE_ROLE_KEY
   - SUPABASE_ANON_KEY
   - SUPABASE_STORAGE_BUCKET = diary-photos
   - RESEND_API_KEY        (https://resend.com — sin esto el correo casi nunca llega)
   - EMAIL_FROM            = Kitty <noreply@tudominio.com>  (despues de verificar dominio)
3. Resend (correo real):
   - Crear cuenta en https://resend.com
   - API Keys → Create → copiar a Vercel como RESEND_API_KEY
   - Domains → Add domain → poner DNS → esperar verified
   - EMAIL_FROM = Kitty <noreply@tudominio-verificado.com>
   - Sin dominio verificado, Resend solo puede enviar a TU propio email de Resend
4. En Supabase → Authentication → Providers → Email:
   - Confirm email = ON
5. En Supabase → Authentication → URL Configuration:
   - Site URL = https://tu-proyecto.vercel.app
   - Redirect URLs = https://tu-proyecto.vercel.app/auth/confirmed
6. En Supabase SQL Editor: ejecutar sql/2026-07-16_email_confirmation.sql
   (si aun no lo corriste)
7. Redeploy en Vercel tras guardar variables
8. Probar: registro → correo de Resend → /auth/confirmed → login
9. Telefono: flutter con --dart-define=API_BASE_URL=https://tu-proyecto.vercel.app
================================================================================
